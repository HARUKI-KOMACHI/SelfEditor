====================================================
  SelfEditor - 操作説明
====================================================

----------------------------------------------------
  画面構成
----------------------------------------------------

[メニューバー]
  File メニューが表示されます。

[コントロール行 1]
  File / BPM / Snap / Zoom / Type / Dir の設定

[コントロール行 2]
  音楽ファイルの読み込みと再生操作

[タイムライン]
  イベントを配置するメインエリア

[ステータスバー]
  操作結果のメッセージが表示されます（緑=成功、赤=失敗）

----------------------------------------------------
  ファイル操作 (File メニュー)
----------------------------------------------------

  New    新規譜面を作成（現在の内容はクリアされます）
  Open   File 欄に指定したパスから譜面 JSON を読み込む
  Save   File 欄に指定したパスに譜面 JSON を保存する

  ※ File 欄のデフォルト: chart.json
  ※ 別名で保存したい場合は File 欄のパスを変更してから Save

----------------------------------------------------
  譜面設定
----------------------------------------------------

  File    保存/読み込みに使用する JSON ファイルパス
  BPM     楽曲の BPM を設定（イベントの位置に影響します）
  Snap    配置スナップの単位を選択
            1 beat / 1/2 / 1/4 / 1/8
  Zoom    タイムラインの表示範囲を調整（4〜64 beats）
  Type    配置するイベントの種類を選択
            Enemy / Obstacle / Gravity / Jump
  Dir     Gravity 選択時のみ表示。重力の方向を選択
            Up / Down / Left / Right

----------------------------------------------------
  音楽再生
----------------------------------------------------

  Music 欄    音楽ファイル名を入力（拡張子まで）
                例: stage01.wav  /  stage01.mp3
                ※ファイルは Assets/music/ フォルダに置くこと
                ※入力するのはファイル名のみ（パス不要）

  Load        音楽ファイルを読み込む
  >           再生開始（現在位置から）
  ||          一時停止（位置を保持）
  []          停止して先頭に戻る

  ※ 対応フォーマット: WAV（PCM）、MP3

----------------------------------------------------
  タイムライン操作
----------------------------------------------------

  左クリック    イベントを配置 / 同位置のイベントを削除（トグル）
  右クリック    イベントを削除
  ホイール      タイムラインを左右にスクロール

----------------------------------------------------
  レーン構成
----------------------------------------------------

  タイムラインは 4 壁 × 3 レーン = 計 12 レーンで構成されます。

  Up-0 / Up-1 / Up-2      (緑)
  Dn-0 / Dn-1 / Dn-2      (赤)
  Lt-0 / Lt-1 / Lt-2      (青)
  Rt-0 / Rt-1 / Rt-2      (黄)

  Gravity イベントは壁・レーンに関係なく全レーンに縦線で表示されます。

----------------------------------------------------
  再生ヘッド
----------------------------------------------------

  音楽再生中、現在の再生位置が黄色い縦線と三角マーカーで
  タイムライン上に表示されます。
  再生ヘッドが画面右端付近に近づくと自動スクロールします。

----------------------------------------------------
  Undo / Redo
----------------------------------------------------

  Ctrl + Z    直前のノーツ操作を取り消す（最大100回）
  Ctrl + Y    取り消した操作をやり直す

  ※ 対象操作: ノーツの配置・削除

----------------------------------------------------
  譜面 JSON フォーマット
----------------------------------------------------

  {
    "music": "stage01.mp3",
    "bpm": 160,
    "events": [
      { "beat": 4.0, "type": "Enemy",   "wall": "Up",   "lane": 1 },
      { "beat": 8.0, "type": "Gravity", "direction": "Left" }
    ]
  }
