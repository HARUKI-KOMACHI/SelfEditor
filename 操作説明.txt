================================================================
  SelfEditor - タイムラインイベントエディタ 操作説明
　(！←これがついている奴は見なくても可）
================================================================

【概要】
SelfEditor は、リズムアクションゲーム向けのステージイベントを
DAW 風のタイムラインに配置するエディタです。
4 つの壁（Up / Left / Down / Right）× 3 レーン = 計 12 レーンに
ノーツを配置し、JSON ファイルとして保存できます。


================================================================
  基本操作
================================================================

【ノーツの配置・削除】
  左クリック    タイムライン上にノーツを配置する
                すでにノーツがある場所をクリックすると削除（トグル）
  右クリック    ノーツを削除する

【タイムライン操作】
  マウスホイール    タイムラインを上下スクロール

【再生コントロール】
  Space    再生 / 一時停止 をトグル切り替え
  Enter    停止して先頭（時刻 0）へ戻る

【シークマーカー】
  M          現在の再生ヘッド位置をマーカーとして記録する
  Shift+M    記録したマーカー位置へジャンプする
  ※ マーカーはタイムライン上にオレンジ色の線で表示されます

【Undo / Redo】
  Ctrl+Z    操作を一つ元に戻す（最大 100 ステップ）
  Ctrl+Y    元に戻した操作をやり直す

【その他】
  Esc    Hold ノーツ配置の途中でキャンセルする


================================================================
  ノーツの種類
================================================================

  Enemy   (●)  塗り円 - 通常ノーツ
  Hold    (  )  平行四辺形バー - 長押しノーツ・壁またぎ可
  Orb     (○)  中抜き円
  Barrier (■)  四角


================================================================
  Hold ノーツの配置方法
================================================================

Hold ノーツは 2 回クリックで配置します。

  1. 1 回目のクリック: 始点（壁・レーン・拍）を指定する
  2. 2 回目のクリック: 終点を指定する（別の壁でも可）

途中でキャンセルしたい場合は Esc を押してください。


================================================================
  スロー再生
================================================================

Speed コンボボックスで再生速度を選択できます。

  0.25x / 0.50x / 0.75x / 1.00x

譜面の細かい確認をしたいときはスロー再生が便利です。


================================================================
  オフセット設定
================================================================

「Offset(s)」フィールドで再生ヘッドのオフセット（秒単位）を
設定できます。音楽と譜面のタイミングがずれる場合に調整してください。


================================================================
　ファイルの保存・読み込み
================================================================

譜面は JSON 形式で保存されます。

【音楽ファイル】
  Assets/music/ フォルダに WAV または MP3 ファイルを置き、
  エディタの「Music」欄にファイル名だけを入力してください。
  （例: stage01.mp3）
  ※ Assets/music/ のパスは自動的に付加されます

！【JSON フォーマット例】
  {
    "music": "stage01.mp3",
    "bpm": 160,
    "events": [
      { "beat": 4.0,  "type": "Tap",     "wall": "Up",   "lane": 1 },
      { "beat": 8.0,  "type": "Hold",    "wall": "Left", "lane": 1,
        "endBeat": 10.0, "endWall": "Down" },
      { "beat": 12.0, "type": "Orb",     "wall": "Down", "lane": 0 },
      { "beat": 16.0, "type": "Barrier", "wall": "Right","lane": 2 }
    ]
  }


================================================================
  ！SE（効果音）
================================================================

Assets/SE/ フォルダに WAV または MP3 ファイルを置くと、
再生中にノーツ通過タイミングで SE が自動的に鳴ります。


================================================================
  壁・レーンの並び順
================================================================

壁の表示順は上から順に:
  Up / Left / Down / Right

各壁に 3 レーン（0・1・2）があります。
Hold ノーツは常に中央レーン（レーン 1）に配置されます。


================================================================
  ！タイムングについて
================================================================

ノーツの位置は「beat（拍）」単位で管理されています。
BPM を変更しても各ノーツの拍上の位置は変わりません。

拍から秒への変換式:
  time(秒) = (60 / BPM) x beat
